# AI Qadam Video Kit: instructions for coding agents

This repository makes promo, pitch and product videos from a conversation. The person
describes the video; you write a brief, a timeline (`video.json`) and scenes in HTML, make
the voiceover, check frames and render an MP4. Rendering is done by
[HyperFrames](https://github.com/heygen-com/hyperframes) (Apache-2.0); motion comes from
the kit's own runtime (`runtime/kit.js`, MIT).

Talk to the person in their language. Files, code and comments stay in English, except
the text that appears in the video itself.

## Before anything else

Read `skills/video-kit/SKILL.md`. It is the workflow, and it says which reference to read
for each step. If your tool loads skills from its own folder (`.claude/skills`,
`.agents/skills`, `.opencode/skills` and the like), the same files can be copied there;
the copy in `skills/` is the one to edit.

## Layout

```
AGENTS.md                 this file (CLAUDE.md and GEMINI.md point here)
skills/video-kit/         the workflow and references, for any agent
kit.mjs                   the command line: node kit.mjs <command>
runtime/kit.js, kit.css   motion runtime the scenes use (window.kit)
lib/                      timeline, sync, voice, sound, checks
templates/video/          what `node kit.mjs new` copies
videos/<name>/            one folder per video
  brief.md                what the video says and where each fact comes from
  video.json              format, scenes, voice lines, sounds, music: all timing lives here
  compositions/<id>.html  one scene per file
  assets/                 photos, fonts, voice/ (generated); CREDITS.md lists every file
videos/tutun-lounge/      the worked example: read it before writing your first scene
```

`index.html`, `meta.json` and `assets/kit/` inside a video are generated by
`node kit.mjs sync` from `video.json`. Never edit them; they are rewritten on every command.

## Commands

```
node kit.mjs new <name> [--format landscape|portrait|square] [--lang ru]
node kit.mjs plan <video>                  when each scene, line and sound plays
node kit.mjs check <video> [--quick]       kit checks, then HyperFrames checks
node kit.mjs stills <video> [scene@sec …]  PNG frames; read them before you reply
node kit.mjs voice <video> [--force id]    voice lines (needs ELEVENLABS_API_KEY in .env)
node kit.mjs render <video> [--quality high]
node kit.mjs preview <video>               live preview for the person (blocks)
node kit.mjs doctor                        environment check
```

## Rules that are never bent

1. **Every number and claim in the video comes from `brief.md`**, where each has a source.
   Do not round differently, combine figures or add features. If a fact is missing, ask.
2. **Look at what you made.** After any visual change run `stills` and read the images.
   After any audio change render and read the loudness line. Code that passes checks can
   still look wrong.
3. **Say what you did not see or hear.** You cannot watch motion or listen to sound; say so
   when you deliver, in one line.
4. **Credit every asset** in `assets/CREDITS.md` (source, author, license). Prefer CC0,
   CC BY and public domain. Never redraw a real brand's logo, and never put recognisable
   real people next to a brand they do not work for.
5. **Keys stay out of the repository.** They live in `.env` (gitignored) or the environment.
6. **Do not install the HyperFrames agent skills or use HeyGen services** unless the person
   asks: they assume GSAP and HeyGen accounts, and this kit uses neither. The HyperFrames
   CLI itself is used through `node kit.mjs`.
